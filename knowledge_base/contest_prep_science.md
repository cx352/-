
Contest Prep Science — 自然健美备赛科学知识库
1. 文件定位
本文件用于建立自然健美备赛阶段的科学决策框架。
核心目标：
• 最大程度降低体脂
• 最大程度保留肌肉
• 尽可能维持训练表现
• 管理疲劳与恢复
• 控制备赛速度
• 处理赛前最后阶段
• 建立安全、可重复的 Peak Week 框架
• 避免使用没有充分证据支持的极端操作
核心原则：
备赛不是单纯“减体重”，而是在有限时间内降低脂肪，同时尽可能保留肌肉、力量和视觉表现。
--------------------
2. 备赛基本模型
Contest Prep =Fat Loss+Muscle Retention+Performance Management+Recovery Management+Peak Presentation
因此：
体重下降 ≠ 备赛成功。
需要同时观察：
• 体重
• 腰围
• 视觉状态
• 训练表现
• 肌肉围度
• 恢复
• 饥饿
• 睡眠
• 有氧
• 步数
--------------------
3. 备赛开始时间
备赛周期不能简单按照固定周数决定。
应根据：
• 起始体脂
• 目标体脂
• 当前肌肉量
• 预计比赛体重
• 每周可接受减重速度
• 训练能力
• 恢复能力
估算所需时间。
原则：
越早建立可控的减脂速度，越不需要依赖最后阶段极端操作。
如果已经非常接近比赛，而体脂仍明显高于目标：
• 不应简单通过无限增加有氧解决
• 应评估是否需要延长备赛周期
• 或重新调整比赛目标
--------------------
4. 体重下降速度
备赛期间不应追求固定的绝对减重速度。
更合理的方法：
使用体重百分比/周。
根据不同阶段和个体情况动态调整。
一般情况下：
• 较高体脂阶段可以承受相对较快下降
• 越接近比赛，减重速度通常越需要谨慎
• 越低体脂，肌肉流失风险和恢复压力通常越高
重要：
减重速度只是起始框架，不是硬性规则。
必须结合：
• 训练表现
• 腰围
• 视觉变化
• 恢复
• 饥饿
综合判断。
--------------------
5. 热量赤字
备赛核心仍然是长期能量负平衡。
可以通过：
• 降低摄入
• 增加活动
• 有氧
• 步数
• 或组合
建立热量赤字。
但不应一次性制造过大的赤字。
原则：
使用能够持续执行，同时尽可能保护训练表现和肌肉的最小有效赤字。
--------------------
6. 热量调整
当体重趋势下降：
如果
体重下降+腰围下降+训练表现基本稳定
→ 通常无需调整。
如果
体重长期不下降+腰围不下降
→ 检查：
• 食物记录
• 烹饪油
• 零食
• 饮料
• 周末饮食
• 步数
• 有氧
• 体重记录
确认数据后，再进行小幅调整。
如果
体重下降过快+训练表现下降+恢复恶化
→ 考虑：
• 增加摄入
• 降低有氧
• 降低活动压力
• 减少训练疲劳
--------------------
7. 蛋白质
备赛阶段蛋白质的重要性较高。
主要作用：
• 支持肌肉蛋白合成
• 帮助维持瘦体重
• 提高饱腹感
• 为减脂期提供稳定蛋白质供应
实践框架：
蛋白质通常保持在较高且稳定的水平，而不是随着每天体重波动频繁调整。
可以使用：
约 1.6–2.2 g/kg/day
作为常规起始范围。
在高水平备赛、低体脂或较大赤字阶段，可以根据实际情况调整。
不要机械追求极高蛋白质。
--------------------
8. 碳水化合物
碳水是备赛训练表现的重要营养来源。
主要影响：
• 肌糖原
• 训练表现
• 训练容量
• 泵感
• 肌肉视觉饱满度
• 恢复
减脂并不意味着必须持续降低碳水。
应根据：
• 总热量
• 训练表现
• 活动量
• 体重趋势
• 比赛阶段
动态调整。
--------------------
9. 脂肪
脂肪需要保持在合理范围。
过度降低脂肪可能增加：
• 饮食执行困难
• 饱腹感问题
• 食物选择受限
但脂肪也属于高能量密度营养素。
如果减脂停滞：
应检查实际脂肪摄入，包括烹饪油、坚果、酱料等隐性热量。
--------------------
10. 训练策略
备赛训练的核心目标：
最大程度保留已有肌肉。
因此：
不能简单理解为：
“减脂期就应该使用轻重量高次数。”
肌肉保留的重要信号之一是：
持续提供足够的机械张力。
训练可以继续使用：
• 中高负荷
• 足够接近力竭
• 合理训练量
• 稳定动作技术
但随着恢复能力下降：
可以优先减少训练量，而不是完全放弃训练强度。
--------------------
11. 训练量调整
减脂早期：
可以尽量维持原有有效训练量。
随着备赛深入：
如果出现：
• 恢复下降
• 表现下降
• 睡眠下降
• 饥饿增加
• 有氧增加
可以逐渐降低训练量。
优先减少：
• 低价值训练
• 重复刺激
• 高疲劳动作
• 不必要的力竭组
而不是随机删除核心动作。
--------------------
12. 力竭
备赛期间不需要每组都训练到力竭。
尤其是：
• 深蹲
• 硬拉
• 高疲劳推举
• 高疲劳划船
应谨慎使用力竭。
孤立动作可以更接近力竭。
原则：
在恢复能力下降时，提高刺激/疲劳比，而不是最大化疲劳。
--------------------
13. 有氧
有氧是增加能量消耗的工具。
常见方式：
• 步行
• 坡走
• 自行车
• 椭圆机
• 其他低冲击有氧
选择时考虑：
• 能量消耗
• 对腿部恢复的影响
• 对力量训练的干扰
• 执行便利性
• 个人偏好
原则：
使用能够长期执行且不会明显破坏力量训练质量的有氧形式。
--------------------
14. 步数
步数是非常有价值的备赛工具。
优势：
• 强度低
• 容易长期执行
• 恢复成本通常较低
• 可以形成稳定活动量
备赛期间应尽可能保持活动量稳定。
例如：
如果平时每天约7000–8000步：
不要突然变成：
15000–20000步
然后又大幅下降。
更重要的是：
稳定的日常活动量。
--------------------
15. 有氧增加顺序
如果减脂停滞，可以按照：
1. 检查饮食准确性
2. 检查步数
3. 检查体重数据
4. 检查训练表现和恢复
5. 小幅调整热量
6. 小幅增加有氧
不要同时：
• 大幅降低热量
• 大幅增加步数
• 大幅增加有氧
• 大幅增加训练量
否则无法判断哪个变量产生了影响。
--------------------
16. 体重波动
备赛期间体重会受到：
• 糖原
• 水分
• 钠
• 肠道内容物
• 炎症
• 训练
• 压力
影响。
因此：
不应该根据单日体重决定是否调整热量。
优先使用：
7日平均体重。
进一步结合：
14日趋势+28日趋势。
--------------------
17. 腰围
腰围是重要辅助指标。
例如：
体重下降+腰围下降+训练表现稳定
通常说明减脂进展合理。
如果：
体重不变+腰围下降+力量稳定/上升
可能存在：
体脂下降 + 瘦体重/糖原/水分变化。
不要因为体重不变就立即降低热量。
--------------------
18. 肌肉保留判断
备赛期间肌肉是否得到较好保留，应综合：
• 训练表现
• 肌肉围度
• 视觉厚度
• 体重变化
• 腰围变化
• 恢复
不能只通过体脂秤判断肌肉变化。
生物电阻抗等工具可能受到：
• 水分
• 糖原
• 钠
• 饮食
• 训练
影响。
因此：
趋势比单次体脂率测量更有价值。
--------------------
19. 低体脂阶段
当体脂已经很低：
通常会出现：
• 饥饿增加
• 恢复下降
• 睡眠变化
• 训练表现下降
• 情绪压力增加
• 日常活动下降
• 肌肉保留难度增加
因此：
越接近比赛：
越需要控制额外疲劳。
不要把最后阶段变成无限增加训练量。
--------------------
20. 自发活动下降
长期减脂可能导致NEAT下降。
例如：
• 走路减少
• 坐着时间增加
• 日常动作减少
因此即使“饮食没有变化”，实际能量消耗也可能下降。
备赛监控应包括：
• 步数
• 日常活动
• 有氧
• 训练
避免只看热量摄入。
--------------------
21. 训练表现下降的判断
轻微下降不一定代表肌肉流失。
可能原因：
• 肌糖原下降
• 水分下降
• 热量不足
• 睡眠不足
• 累积疲劳
因此：
需要观察持续趋势。
如果：
表现略下降+视觉状态改善+腰围下降
不一定需要立即增加热量。
如果：
表现持续下降+恢复恶化+体重下降过快
则需要调整备赛策略。
--------------------
22. 比赛前最后阶段
比赛前最后阶段的目标：
• 达到目标体脂
• 保持肌肉
• 控制疲劳
• 优化视觉表现
• 保证舞台状态
不是：
尽可能让体重降到最低。
比赛体重不是唯一目标。
最终外观受到：
• 肌肉量
• 体脂
• 糖原
• 水分
• 肠道内容物
• 肌肉充盈
• 皮下水分
• 姿势和展示
共同影响。
--------------------
23. Peak Week 基本原则
Peak Week 应以：
稳定、可预测、低风险
为优先级。
不要因为网络上的极端案例而进行：
• 极端脱水
• 极端限水
• 极端钠操作
• 长时间断水
• 极端碳水耗竭
• 未知药物/利尿剂操作
这些方法可能带来严重风险，而且个体反应高度不可预测。
--------------------
24. 碳水加载
碳水加载的目的通常是：
• 恢复肌糖原
• 增加肌肉视觉饱满度
但碳水增加也会伴随：
• 糖原储存
• 水分变化
• 肠道内容物增加
因此：
不应该认为“碳水越多越饱满”。
实际方案应根据：
• 过去备赛经验
• 当前体重
• 肌糖原状态
• 消化能力
• 食物选择
• 舞台时间
进行个体化。
--------------------
25. 水与钠
水和钠是Peak Week中高度敏感的变量。
不应机械执行：
“断水”+“极端低钠”。
因为体液平衡受到复杂的生理调节。
极端操作可能导致：
• 脱水
• 电解质紊乱
• 血压异常
• 肌肉抽搐
• 严重健康风险
因此：
水和钠原则上保持稳定，除非有充分专业依据进行调整。
--------------------
26. 利尿剂
不应在普通健身指导中提供：
• 利尿剂使用方案
• 剂量
• 时间安排
• 联合用药方案
原因：
利尿剂可能导致：
• 电解质紊乱
• 严重脱水
• 心律问题
• 肾脏风险
• 生命危险
任何药物性Peak Week策略应由具备相关资质的医疗专业人员管理。
--------------------
27. 比赛当天
比赛当天优先考虑：
• 正常饮水
• 稳定电解质
• 容易消化的食物
• 适度碳水
• 控制肠胃负担
• 保持肌肉充盈
• 合理热身
避免第一次尝试：
• 新食物
• 新补剂
• 大量糖
• 大量脂肪
• 极端饮水
• 极端盐摄入
--------------------
28. Pump Up
Pump Up的目标：
提高肌肉视觉充盈，而不是制造疲劳。
应优先：
• 轻重量
• 中高次数
• 目标肌群
• 低疲劳
• 避免大量乳酸堆积影响舞台状态
不要把Pump Up训练成正式训练课。
--------------------
29. 消化系统
比赛前需要考虑：
• 食物体积
• 纤维
• 食物残渣
• 乳糖耐受
• 高脂肪食物
• 碳酸饮料
• 个人消化能力
如果某种食物过去容易造成腹胀：
比赛前不应突然大量使用。
--------------------
30. 备赛心理
长期低体脂可能产生明显心理压力。
可能表现：
• 对体重过度关注
• 对每日外观变化敏感
• 对食物焦虑
• 对减脂速度焦虑
因此：
不应根据镜子中的单日变化反复调整饮食。
应该依赖：
• 周平均体重
• 腰围
• 训练表现
• 固定条件照片
• 计划周期
进行决策。
--------------------
31. Natural Athlete Case Database 的使用
运动员案例可以帮助回答：
• 某运动员如何安排训练
• 某运动员备赛多久
• 训练量如何变化
• 有氧如何安排
• 碳水如何变化
• 赛前如何调整
但是：
案例不是因果证据。
必须区分：
Documented
来源明确记录。
Athlete-reported
运动员本人描述。
Derived
根据体重、饮食等数据计算。
Unknown
缺乏可靠数据。
--------------------

33. Decision Engine 备赛判断
情况A
体重下降+腰围下降+表现稳定
→ 保持方案。
--------------------
情况B
体重稳定+腰围下降+表现稳定
→ 继续观察，不立即调整。
--------------------
情况C
体重稳定+腰围稳定+连续14天以上无明显变化
→ 检查数据准确性，再小幅调整。
--------------------
情况D
体重快速下降+表现下降+恢复恶化
→ 赤字可能过大。
--------------------
情况E
体重下降+表现轻微下降+视觉持续改善
→ 观察趋势，不立即增加热量。
--------------------
情况F
体重下降+表现持续下降+睡眠/恢复明显恶化
→ 降低疲劳并重新评估热量与训练。
--------------------
34. 备赛调整幅度
每次调整应尽量小。
优先：
• 小幅热量调整
• 小幅增加步数
• 小幅增加有氧
• 小幅减少训练量
避免：
• 大幅降碳水
• 大幅增加有氧
• 大幅降低总热量
• 同时改变多个变量
核心：
一次改变尽可能少的变量。
这样才能判断个体反应。
--------------------

37. 核心规则
17. 备赛目标不是单纯降低体重。
18. 核心目标是降低脂肪并尽可能保留肌肉。
19. 体重必须看趋势。
20. 腰围是重要辅助指标。
21. 训练表现是肌肉保留的重要参考。
22. 蛋白质应保持稳定且充足。
23. 碳水不应因为减脂而机械降到极低。
24. 有氧是工具，不是目标。
25. 步数可以作为稳定活动量工具。
26. 训练量应根据恢复能力调整。
27. 低体脂阶段应更加重视恢复。
28. Peak Week优先稳定和可预测。
29. 不使用极端脱水、断水、极端低钠等危险操作作为默认策略。
30. 不提供利尿剂等药物性Peak Week操作方案。
31. 比赛当天不应大量尝试新食物或新策略。
32. Athlete Case不能替代科学证据。
33. Documented、Athlete-reported、Derived、Unknown必须严格区分。
34. 一次尽量只调整少数变量。
35. 7/14/28天趋势优先于单日数据。
36. 最终目标是最大化舞台状态，而不是最大化减重速度。
